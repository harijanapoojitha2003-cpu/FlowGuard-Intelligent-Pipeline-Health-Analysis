About FlowGuard

FlowGuard is an intelligent pipeline monitoring system designed to analyze pipeline conditions and predict potential risks using machine learning techniques.

Key Features:
  • Real-time pipeline monitoring
  • Risk prediction (Low / Medium / High)
  • Graphical visualization
  • Worker safety decision support
Technologies Used:
  • Python & Flask
  • Machine Learning Algorithms
  • HTML, CSS, Bootstrap
Use Case:

This system helps industries prevent accidents, detect pipeline issues early, and ensure worker safety.
